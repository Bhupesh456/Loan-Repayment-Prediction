# Output Files

This folder contains the prediction results generated by the trained **Logistic Regression** model.

## Files

### Loan_Repayment_Logistic_Regression.csv

- **Purpose:** Stores the predicted loan repayment status for the unseen test dataset.
- **Generated By:** `Loan_Repayment.ipynb`
- **Model Used:** Logistic Regression

## Description

The output file contains the predictions made by the trained model on the unseen test dataset (`Loan_Repayment_Test_Data_NoLabel.csv`). These predictions can be used for further analysis or submission, depending on the project requirements.

## Output Columns

| Column | Description |
|--------|-------------|
| Predicted_Repayment *(or your prediction column name)* | Predicted loan repayment status generated by the Logistic Regression model. |

> **Note:** The output file is automatically generated after running the Jupyter Notebook successfully.

## Reproducing the Output

To regenerate this file:

1. Open `notebook/Loan_Repayment.ipynb`.
2. Run all notebook cells from top to bottom.
3. The prediction file will be automatically saved in this folder.
