# Project Visualizations

This folder contains the visualizations generated during the evaluation of the **Loan Repayment Prediction using Logistic Regression** project.

These images provide insights into the model's performance and help interpret the results.

---

## Images

### confusion_matrix.png
- **Description:** Displays the number of correct and incorrect predictions made by the Logistic Regression model.
- **Purpose:** Helps evaluate the model by identifying True Positives, True Negatives, False Positives, and False Negatives.

### roc_curve.png
- **Description:** Shows the Receiver Operating Characteristic (ROC) Curve of the model.
- **Purpose:** Evaluates the model's ability to distinguish between the two classes across different classification thresholds.

### feature_importance.png
- **Description:** Visualizes the Logistic Regression coefficients for each feature.
- **Purpose:** Identifies the features that have the greatest influence on predicting loan repayment.

---

## Usage

These images are referenced in the main project documentation (`README.md`) to illustrate the model evaluation process and improve project readability.

---

## Notes

- All visualizations are generated automatically by running the Jupyter Notebook located in the `notebook/` folder.
- If the notebook is executed again, these images can be regenerated and updated with the latest results.
